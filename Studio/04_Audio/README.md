# Audio

Music and sound design. The smallest department right now — genuinely minimal, not just under-documented.

**Owner**: unstaffed. No one is actively working audio.

## Current state

- `scripts/audio/audio_manager.gd` — plays one looping track at a time, swaps based on selected wizard class or biome. Functional, no rough edges, but that's the whole system.
- Existing tracks (placeholder/temp, not confirmed final): `Bad John Dillo Fixed.mp3`, `Fire Wizard.mp3`, `Evangalion.mp3`, `vampire mushroom forest.mp3`.
- No sound effects system found for combat, UI, or unit abilities — hits, casts, deaths, building placement all appear to be silent right now.

## Open items

- No design brief exists for what SFX are actually needed (combat hits, ability casts, UI feedback, ambient biome sound). Worth writing one once Art/gameplay feel is more locked.
- No decision yet on whether music is licensed, commissioned, or AI-generated.
