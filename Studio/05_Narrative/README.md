## What exists, inferred from naming and design docs (not an actual narrative bible)

- KON: player faction, biological/magic-infused, led by a wizard hero. Naming suggests an "evolution"/corruption theme running through the roster (Terrible Thing → Gripper, Horror → Hunter, etc. per `docs/kon_unit_asset_template.md`), alongside conventional wizard-class flavor (Bad Kon Willow, Hellfire Baby, Evangalion).
- Deom Legion: enemy faction, tiered, hostile, waves + a boss (Mycelium Matriarch / `mycelium_boss`).
- Biome: "Dark Forest Frontier" — corrupted forest setting, ruins, shrines, magical mushrooms.

None of this has been written up as an actual story, setting bible, or unit backstory document.
