# Dark Forest Frontier V2 Status

## Goal

`DARK_FOREST_FRONTIER_V2` replaces the prototype's major debug visuals with large, readable dark forest silhouettes based on the concept target: black twisted trees and roots, blue/green mossy ground, muddy paths, dark swamp water, mossy cliff stone, ruins, and hot pink/red magical mushroom accents.

## Renderer Integration

`scripts/map/map_3d_renderer.gd` now defaults BIOME mode to:

- asset pack `res://resources/asset_packs/dark_forest_frontier_v2_asset_pack.json`
- biome name `DARK_FOREST_FRONTIER_V2`
- subtle plot marker materials
- dark moonlit fog
- magenta point lights near mushroom clusters, mushroom rings, corrupted altars, and shrines
- large blocker silhouettes from ancient trees, root walls, mushrooms, dead spikes, and mossy rocks

DEBUG mode remains available and keeps bright diagnostic roads, ramps, bases, content plots, and path overlays.

## Fallback Status

Expected target:

- Main terrain/blocker/plot categories should report no missing categories.
- Renderer fallback usage should remain zero for the V2 showcase.

Fallbacks remain intentionally available for missing paths or broken imports.

## Known Limitations

- Ground, high ground, roads, and water still use procedural surface meshes with V2 materials in the map renderer; their GLB tile assets are generated and registered for preview/future replacement.
- Roads are continuous overlapped renderer meshes, not authored spline meshes.
- Ramps use embedded procedural ramp geometry for reliable plateau attachment; the V2 ramp GLBs are registered and available, but the renderer prioritizes physically connected geometry.
- Assets are intentionally stylised placeholders, not final art.
